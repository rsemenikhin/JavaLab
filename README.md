# Лабораторная работа 3

Проект сравнивает производительность `ArrayList` и `LinkedList`.

Проверяемые операции:

- `add`
- `get`
- `delete`

Для каждой операции программа:

- выполняет метод заданное количество раз
- измеряет время выполнения
- выводит результаты в виде таблицы

## Структура проекта

- `src/main/java` - основной код приложения
- `src/test/java` - unit-тесты
- `pom.xml` - Maven-конфигурация проекта

## Запуск

Запуск тестов:

```bash
mvn test
```

Запуск программы со стандартным количеством операций:

```bash
mvn exec:java "-Dexec.mainClass=ru.mpei.lab3.App"
```

Запуск программы со своим количеством операций:

```bash
mvn exec:java "-Dexec.mainClass=ru.mpei.lab3.App" "-Dexec.args=2000"
```
