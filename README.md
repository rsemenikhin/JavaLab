# Expression Interpreter

Консольное приложение вычисляет арифметические выражения с числами, скобками,
базовыми операциями, переменными и несколькими встроенными функциями.

## Возможности

- операции `+`, `-`, `*`, `/`, `^`
- унарные `+` и `-`
- скобки и проверка корректности записи
- переменные с интерактивным запросом значений
- константы `pi` и `e`
- функции `sin`, `cos`, `abs`, `sqrt`, `log`, `pow`, `min`, `max`
- unit-тесты на корректные и ошибочные сценарии

## Запуск

```bash
mvn test
mvn exec:java -Dexec.mainClass="ru.mpei.lab2.App"
```

## Примеры работы


```text
Введите выражение: max(a, 5) + sqrt(b)
Введите значение переменной a: 7
Введите значение переменной b: 9
Результат: 10.0
```
